# @monsef-nbj/najm-server

Najm's executable development, production-build, and preview server entry
modules. These subpaths run against the current project when loaded and are
intended for Najm tooling rather than application imports:

```text
@monsef-nbj/najm-server/dev
@monsef-nbj/najm-server/build
@monsef-nbj/najm-server/serve
```
