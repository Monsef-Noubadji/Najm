# Security policy

## Supported versions

Security fixes target the current stable `1.x` line. Upgrade to the latest stable release before reporting a version-specific issue.

## Reporting

Do not open a public issue. Use GitHub's **Privately report a security vulnerability** option in this repository's Security tab. Include affected versions, impact, reproduction, and any suggested mitigation. Maintainers will acknowledge the report, assess severity, coordinate a fix and disclosure, and credit reporters who want attribution.
