# CLI

The `najm` CLI remains repository-only during this beta. Framework contributors can run `npm run cli -- <command>` from the checkout. Application engineers should use Vite and the published package entry points documented in [Getting started](./getting-started).

Repository commands include development, build, preview, test, benchmark, and language-server workflows. Do not add a global CLI dependency to production automation until a standalone CLI package is published and documented.
