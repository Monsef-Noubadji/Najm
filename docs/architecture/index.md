# Architecture

Najm compiles `.najm` source into coordinated server rendering and browser claim programs. The runtime supplies ownership, fine-grained signals, DOM bindings, SSR request isolation, and island hydration. The router adds filesystem resolution before server rendering.

Use these pages for system orientation, then follow links to the RFCs for decisions and tradeoffs: [Compiler](./compiler), [Runtime](./runtime), [SSR and hydration](./ssr-and-hydration), [Security](./security), and [Performance](./performance).
