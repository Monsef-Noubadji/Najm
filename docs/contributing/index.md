# Contributing

Najm welcomes focused bug fixes, documentation improvements, tests, and RFC-backed design work.

```bash
npm ci
npm test
npm run typecheck
```

Keep changes scoped, add tests before implementation, update user documentation when behavior changes, and add a Changeset for published-package impact. Read [Testing](./testing), [RFCs](./rfcs), and [Releases](./releases) before opening a pull request.
