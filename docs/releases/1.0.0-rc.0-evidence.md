## Benchmarks

The benchmark runner originally measured sub-millisecond signal latency after fixture-build and browser work, causing false regression reports. Commit `1b61cdf` moved that measurement ahead of contaminating work and added `tests/test-benchmark-runner.ts`.

A fresh combined run after the fix reported no metric beyond the 5% baseline: signal medians improved by approximately 31% and 51%, hydration medians changed by -1.5% and -1.7%, and hydration ratio was 2.25x within its 3x bound. A later complete-chain run showed one intermittent wall-clock signal sample at +33% while all deterministic gates passed. This variability is explicitly carried into RC hardening; stable promotion requires repeat evidence that distinguishes environment noise from a reproducible regression.
