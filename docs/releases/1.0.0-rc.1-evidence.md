# Najm 1.0.0-rc.1 evidence

## Candidate

`1.0.0-rc.1` is the coordinated corrective candidate following clean-room adoption of `rc.0`. It contains no public API expansion. The behavioral changes are limited to published server application-root resolution, Vite plugin deduplication, and preview root resolution.

## Automated evidence

- `npm test`: passed after converting the tracked `testing.najm` experiment to valid SFC syntax.
- `npm run typecheck`: passed.
- `npm run test:packages`: passed, including imports and a production build from packed tarballs with the documented Vite configuration.
- `npx tsx tests/test-release-channel.ts`: passed.
- `git diff --check`: passed; line-ending notices only.

## Package artifacts

All four package manifests and the lockfile use `1.0.0-rc.1`. Dry package builds produced four tarballs with no CLI `bin` field. The server tarball remained approximately 71 kB packed and 249 kB unpacked.

## Adoption evidence

See [the clean-room adoption report](./1.0.0-adoption-report). Production build, development server, preview server, routing, middleware, stores/context, SSR boundary recovery, and both browser hydration strategies were exercised outside the repository.

## Known warnings

The repository audit continues to report three dependency findings (two moderate and one high) pending explicit classification. Advanced documentation needs complete executable examples before stable promotion. `rc.0` remains historical and must not be promoted.
