# Najm 1.0.0 evidence

## Release decision

`1.0.0` promotes the coordinated `1.0.0-rc.1` package set without framework behavior changes. A source diff from `v1.0.0-rc.1` across the runtime, compiler, router, server, and package entry points is empty. The stable changes remove prerelease state, finalize package versions and changelogs, and update engineer-facing documentation to use the stable channel.

The CLI remains deferred and is not included in any published package.

## Automated evidence

The evidence gate was run from a fresh `npm ci` installation on July 15, 2026.

- `npm test`: passed all registered suites, including runtime, compiler, router, server, release, documentation, package smoke, API stability, and bundle-size assertions.
- `npm run typecheck`: passed with no TypeScript errors.
- `npm run build:packages`: built all four packages at `1.0.0`.
- `npm run test:packages`: passed registry-shaped consumer imports and production build verification.
- `npm run bench`: completed. Bundle metrics were within the hard gate and hydration passed its scaling tolerance. One reported-only signal latency metric varied by `+28.5%`; signal latency is not a release gate and the correctness and bundle gates passed.
- `npm run docs:check`: built the complete VitePress site successfully.
- `git diff --check`: passed; Git emitted line-ending notices only.
- `npm pack --json --workspaces --dry-run`: produced valid manifests for all four public packages with no CLI binary.
- Release-specific version, documentation, and content assertions passed independently before the full suite.

## Adoption evidence

The [clean-room adoption report](./1.0.0-adoption-report) records an external engineer workflow against registry packages. It covers production build, development and preview servers, routing, middleware, stores and context, SSR error recovery, and eager and visible browser hydration. The documentation gaps found during that exercise now have complete examples for routing structure, stores/context, and error boundaries.

## Security and issue review

GitHub reports no open issues at the release checkpoint. `npm audit` reports three development-tool findings: two moderate and one high. They resolve through the documentation toolchain (`vitepress` to nested `vite`/`esbuild`), have no available npm fix in the current dependency graph, and are absent from the published package dependency graphs. They do not affect Najm production runtime artifacts, but remain tracked as toolchain upgrade work.

## Promotion criteria

- Four coordinated packages at `1.0.0`.
- No framework behavior drift from the accepted `rc.1` candidate.
- Full local quality gate passed from a clean install.
- Registry-shaped consumer build passed.
- Clean-room adoption evidence exists and documentation findings are addressed.
- No open release-blocking issues.
- CLI remains explicitly deferred.
