# Where the documentation moved

The single-file technical manual that used to live here described the
Beta architecture (meta-islands, deep React/Vue runtime embedding,
resumability as a v1 feature) that was superseded by the architecture
review and is now archived — see [legacy/README.md](https://github.com/Monsef-Noubadji/Najm/blob/main/legacy/README.md)
and [legacy/docs/MANUAL.md](https://github.com/Monsef-Noubadji/Najm/blob/main/legacy/docs/MANUAL.md) for the historical
version.

Current architecture documentation is the RFC series:
**[docs/rfcs/README.md](rfcs/README.md)**, starting with
[RFC-0001 (Vision & Philosophy)](rfcs/RFC-0001-vision-and-philosophy.md).
